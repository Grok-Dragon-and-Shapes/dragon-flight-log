# dragon-flight-log

Журнал полётов дракона над биомами: дата, биом, высота и заметка. Открой `index.html` в браузере. Данные хранятся в localStorage этого браузера.

## Что есть

- Запись полёта с проверкой высоты (0–400 блоков).
- Сводка: число полётов, максимальная высота, сколько биомов пройдено.
- Удаление отдельных записей.

## Где менять списки

Биомы лежат в начале `app.js` (`BIOMES`).
